# Advanced SystemCare — 100 Article GitHub Pages Site

Upload `index.html`, `style.css`, `support.html`, `.nojekyll`, and the entire `articles/` folder to the root of your GitHub repository. In Settings > Pages, publish from the main branch and root folder. The homepage intentionally contains no article listing. Each article is accessible by its filename under `/articles/`.

This site is independent and not affiliated with IObit or Advanced SystemCare. Support buttons point to the local support-information page; no external payment or login links are embedded.
